# Original bus design

The active icons in `public/images/` are the user's updated designs, imported from `dist/images/` on October 21, 2026. Edit the files in `public/images/` for future changes; builds regenerate `dist/` from those sources.

Both **Detailed** and **Classic** card layouts use the updated icons. The 11 original illustrations remain in `original-bus-art/`, and the previous enhanced icons are in `before-user-icons-2026-10-21/`.

The old `scripts/enhance_bus_icons.py` now writes only to `design-backup/generated-detail-pass/` so it cannot overwrite the current user artwork.
